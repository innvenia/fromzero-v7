# Backend API

## Cobertura

Node.js, Express, NestJS, FastAPI, Django, Flask, Rails, Laravel, Go, Spring y APIs similares.

## Gates

- Contratos request/response definidos.
- Validación en trust boundaries.
- Autenticación y autorización server-side.
- Rate limits para operaciones sensibles.
- Errores seguros.
- Logs sin secretos ni PII innecesaria.
- Observabilidad mínima.

## Seguridad

- SQL parametrizado o ORM seguro.
- No confiar en headers manipulables.
- Validar tenant ownership en servidor.
- Proteger webhooks con firma.

## Faltantes

Si el framework no esta cubierto, usar recurso genérico y activar `missing-resource-resolution` para reglas oficiales.
