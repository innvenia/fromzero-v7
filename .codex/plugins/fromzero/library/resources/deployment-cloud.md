# Deployment and cloud

## Cobertura

Vercel, Netlify, Railway, Render, Fly.io, Hostinger, AWS, GCP, Azure, Cloudflare, Docker, Kubernetes y targets similares.

## Gates

- Target de deployment definido.
- Variables y secrets fuera del repo.
- TLS definido.
- Healthcheck.
- Logs y observabilidad.
- Backup y rollback.
- Capacity notes para release.

## Seguridad

- Least privilege para tokens y service accounts.
- No imprimir credenciales.
- Separar environments.
- Revisar public exposure de APIs y storage.

## Faltantes

Si el proveedor requiere pasos específicos, activar `missing-resource-resolution`.
